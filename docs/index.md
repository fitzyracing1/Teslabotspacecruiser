# TSB-01 Hex Panel Interface Control Document

This repo is a specification document, not software. It describes the TSB-01 "Tesla Bot Space Cruiser", a modular spacecraft concept assembled on orbit from standardized hex panels by Optimus-class humanoids. The ICD (Rev A) lives in `README.md`, beginning with section 1, "Panel geometry".

| Path | Content |
|---|---|
| `README.md` | the ICD |
| `docs/index.html` | website version |
| `docs/assets/schematics/*.jpeg` | schematic photos |
| `CONTRIBUTING.md` | how to contribute |

There is nothing to install or run. To view the site locally, run `python3 -m http.server -d docs`.
